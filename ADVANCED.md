# Beyond the default Guard

The default product exposes a small operation boundary: intent, admission, Broker binding, evidence and Shadow. It uses the existing IMMUNE admission kernel while leaving advanced runtime modules outside the package's default execution path.

The broader Engine contains separate Recovery, Governance and Adaptive evolution mechanisms. Those address authority lifecycle, incident/requirement/candidate evidence, independent verification, delegated promotion and recovery/fork controls. They require their own trust roots, policies, evidence contracts and validation. They are not prerequisites for this local Guard quickstart and not implicit features activated by the preview.

Advanced evidence schemas remain versioned separately. Unsupported states stop unresolved; Guard does not invent recovery authority or promote candidates automatically. Preservation of local advanced tests is evidence of regression coverage, not real hostile-production adaptive performance. No public advanced-source distribution or API stability promise is made here.
