# Request a Shadow Pilot

One action: request a scoped Shadow pilot by emailing **immune@orimusu.com**, or by opening a Discussion once Discussions are enabled. This document does not itself submit or transmit anything. Please replace `immune@orimusu.com` in published copies with a mailbox that has been tested for inbound delivery.

Best fit: teams with AI Agent GitHub writes or internal automation, one initial operation with a narrow rollbackable scope, and a human owner. After review, one to three operations can be considered. Criticality must be disclosed; first observation should avoid production-critical targets.

Intake is a discussion, not permission to install, change branch rules or create credentials. Agree on repository/system identity, scope, retention, original-outcome source, stop mechanism and local evidence location. Observe false-positive behavior, unresolved reasons, latency, evidence reliability and setup friction. End with a human decision; no automatic move to enforcement or organization-wide rollout.

## What we ask for

Only: company/team; a contact name and business contact; the system; the Agent framework, if any; the proposed protected operation; a description of the current credential model (a description only); whether Shadow is wanted; environment/OS and deployment constraints; criticality and the rollback/stop method.

Never send passwords, tokens, keys, PINs, credential files, full source code, environment dumps or sensitive operation payloads. If a message contains something that looks like a secret, we will ask for a redacted description instead.
